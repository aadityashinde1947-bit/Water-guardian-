WATER GUARDIAN — GitHub Pages setup

This is a React/Vite project. Do not upload only App.jsx or rename it to index.html.

1. Extract this ZIP.
2. Upload all files and folders inside water-guardian-site to the ROOT of your GitHub repository (including the hidden .github folder and its workflows/deploy.yml file). If using GitHub's website, make sure .github/workflows/deploy.yml is included; uploading folders through the browser can be awkward, so GitHub Desktop or git is recommended.
3. In your repository, open Settings > Pages.
4. Under Build and deployment, set Source to GitHub Actions.
5. Open the Actions tab and wait for “Deploy Water Guardian to GitHub Pages” to finish successfully.
6. Your site URL will be https://YOUR-USERNAME.github.io/REPOSITORY-NAME/

If the repository has a different name, the URL uses that repository name. This app uses client-side React and requires the workflow to build it before publishing.
